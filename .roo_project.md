# Project Manifest for Roo Code

This file provides a manifest for the Roo agentic IDE. It helps the agent understand the project structure, purpose, and key components.

## Project Information

- **Project Name:** Polis-like Opinion Map Painting
- **Description:** A web-based tool for visualizing opinion maps from Polis conversations. It takes Polis data exports and generates interactive visualizations that can be embedded in other websites.
- **Repository:** [https://github.com/patcon/polislike-opinion-map-painting](https://github.com/patcon/polislike-opinion-map-painting)
- **Version:** 1.0.0

## Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- d3.js
- Python

## Project Structure

### Entry Points

- `index.html`: The main HTML file that loads the application.
- `js/main.js`: The main JavaScript file that initializes the application and handles the core logic.
- `generate.py`: A Python script for pre-processing Polis data.

### Key Directories

- `js/`: Contains all the JavaScript files for the application.
- `data/datasets/`: Contains the datasets used for the opinion maps.
- `assets/`: Contains static assets like images and styles.

### Key Files

- `js/main.js`: Initializes the application, loads data, and orchestrates the rendering of the visualization.
- `js/ui.js`: Handles user interface elements, interactions, and event handling.
- `js/data.js`: Manages data loading, parsing, and preparation for visualization.
- `js/config.js`: Contains configuration options for the application.
- `index.html`: The main HTML structure of the application.
- `generate.py`: A Python script used to process raw Polis data into a format suitable for the visualization.

## Setup and Usage

1.  To run the project, you can serve the files using a simple HTTP server.
2.  For example, you can use Python's built-in server: `python -m http.server`
3.  The `generate.py` script can be used to process new datasets.
